The unlock page moved

Passkey unlock of osheaf key wallets is now at unlock.opensheaf.org, an origin of its own, and this page does nothing. The osheaf that opened it is older: update it, then run the command again.

The osheaf waiting in the terminal asks for the passphrase after two minutes, or at once if you press Ctrl-C there. To update osheaf:

pipx upgrade opensheaf     # or: pipx install --force "opensheaf[validate] @ git+https://github.com/opensheaf/opensheaf-py"
uvx --refresh …            # with uvx

Passkeys made on this page, for opensheaf.org, are not used any more: their keys still open with the passphrase. Run osheaf key enroll --new-passkey, then osheaf key forget --rp opensheaf.org.
