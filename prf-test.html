Passkey unlock: feasibility test

A test for unlocking OpenSheaf keys with a passkey (WebAuthn PRF extension), as osheaf key unlock would. It creates a test passkey named OpenSheaf test for opensheaf.org, derives a secret from it with Touch ID, and shows only a fingerprint of that secret, never the secret. Nothing is sent anywhere except, when the page was opened by the test listener, the fingerprint to your own computer (127.0.0.1). You can delete the test passkey afterwards in the Passwords app.
